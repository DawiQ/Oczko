# Słownik pojęć — EN, DE

Obowiązuje we wszystkich tekstach aplikacji i sklepu. Zasady: zero słownictwa
hazardu (`PLAN.md` §9, §12 — test `forbiddenWords`), bez żargonu kasyna
(EN: nie „hit / stand / dealer / blackjack / chips / bet”; DE: nie „Einsatz /
Wette / Croupier / Jetons / Kasino”), teksty neutralne płciowo, ton domowej
gry przy stole. Tłumaczymy sens, nie słowa; teksty samouczka i zasad piszemy
od nowa w danym języku.

## Neutralność płciowa

- EN: „you”, „they”; nigdy „he/she” o graczu.
- DE: zwracamy się „du”; o graczach — imię albo „Person”, „wer”, formy
  bezosobowe („Wer zuerst 10 Punkte hat…”); nie „der Spieler”.

## Liczba mnoga

EN, DE: `germanicForm` (1 → one, reszta → many): „1 card / 2 cards”,
„1 Karte / 2 Karten”, „1 Punkt / 2 Punkte”, „1 Runde / 2 Runden”.
